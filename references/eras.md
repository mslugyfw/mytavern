# 史记时代列表

## 可选时代

| 时代 | 时间 | 核心事件 | 特色 |
|------|------|----------|------|
| **五帝三代** | 前2700-前771 | 黄帝→夏→商→西周 | 神话与史实交织，尧舜禹禅让，武王伐纣 |
| **春秋** | 前770-前476 | 齐桓公→孔子 | 诸侯争霸，管仲变法，孔子周游列国 |
| **战国** | 前475-前221 | 商鞅→荆轲→秦统一 | 合纵连横，百家争鸣，铁器战争 |
| **秦** | 前221-前207 | 始皇→沙丘之变→秦亡 | 统一六国，焚书坑儒，长城阿房宫 |
| **楚汉** | 前206-前202 | 项羽→刘邦→垓下 | 鸿门宴，破釜沉舟，四面楚歌 |
| **西汉** | 前202-8 | 文景→武帝→王莽 | 文景之治，汉武大帝，丝绸之路 |

## 选择建议

- 想体验**权谋博弈** → 战国 / 楚汉
- 想体验**帝王之路** → 秦 / 西汉
- 想体验**百家争鸣** → 春秋
- 想体验**史诗神话** → 五帝三代

每个时代包含：相关人物传记、历史事件、地理位置、朝代背景、官职制度。
